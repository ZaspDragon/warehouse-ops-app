WarehouseOS · QR Bin Scanner

OH01 · Draft-only scan-to-scan workflow
← WarehouseOS
Not connected to Bin Manager. Item quantities come only from a CSV you import. Drafts do not move stock or post any Bin Manager transactions. Verify all transfers in Bin Manager using your authorized account. Ask IT to enable HTTPS before transmitting credentials.

1. Scan item and bins

Phone: tap a field then Start camera. Bluetooth/USB keyboard scanners: focus a field and scan; Enter advances to the next field. QR payloads should contain only the item number or location code.

2. Optional item lookup via CSV

Import an approved CSV with columns item,bin,qty,allocated,description. Export from an authorized source; this local lookup is not live. Data stays in this browser tab.

Scan an item to search imported inventory.

3. Review draft transfers

Drafts are saved in this browser's local storage. They are not synchronized between devices and must be manually confirmed in Bin Manager.
